# World Cup 2026 Predictor

Конструктор футбольного прогноза. Результаты групп определяют участников плей-офф, а итоговый прогноз можно сохранить, экспортировать или передать через share-code.

![World Cup 2026 Predictor — Начало прогноза в опубликованной версии](assets/social-preview.jpg)

[Открыть прогноз ↗](https://courageous-elf-34b597.netlify.app/)

Опубликованная демоверсия · Публичная витрина приватного проекта  
React · TypeScript · Vite · Zustand · Vitest

## Что меняется после правки результата

Zustand связывает групповые таблицы, рейтинг третьих мест и сетку плей-офф. Сохранения остаются в браузере, а миграции учитывают изменения формата данных.

**Тестирование.** В документации проекта зафиксировано 26 тестов Vitest. Они охватывают расчёт таблиц и сетки, восстановление прогноза, данные игроков, share-code и экспорт.

Независимый фан-проект. Составы и награды на экранах иллюстрируют работу конструктора.
